# Dodge Rain: โค้ดสำหรับเวิร์กช็อป

รวมโค้ด GDScript สำหรับเขียนเกม Dodge Rain ด้วย Godot 4.7.2 แบ่งตามช่วงที่สอนและส่วนต่อยอด

## 1. โค้ดที่สอนในสไลด์

เลือกโฟลเดอร์ตามจุดที่กำลังทำ แล้วเปิดไฟล์เพื่อดูหรือคัดลอกโค้ดลง script ชื่อเดียวกันในโปรเจกต์ของตัวเอง:

- [01 Player](01_สอนในสไลด์/01_player): `player.gd` สำหรับเคลื่อนที่และจำกัดขอบจอ (checkpoint นาที 75)
- [02 Spawn](01_สอนในสไลด์/02_spawn): Player, Obstacle และ Main สำหรับสุ่มสร้างสิ่งกีดขวาง (checkpoint นาที 115)
- [03 Core game](01_สอนในสไลด์/03_core_game): เพิ่มคะแนน การชน Game Over และเริ่มใหม่ (checkpoint นาที 148)
- [04 เกมสมบูรณ์](01_สอนในสไลด์/04_เกมสมบูรณ์): โค้ดเกมครบ พร้อมส่วนเล่นเสียงเมื่อชน

แต่ละช่วงเป็นโค้ดคนละสถานะของเกม ให้ใช้ไฟล์ในช่วงเดียวกันร่วมกัน และทำตามขั้นตอนสร้าง Scene, Node, Input Map และเชื่อมต่อค่าต่าง ๆ ในสไลด์ ชื่อ Node และพาธต้องตรงกับที่โค้ดอ้างอิง โค้ดเกมสมบูรณ์ต้องมี `HitSound` ใน Main ด้วย

## 2. โค้ดให้น้องทำต่อ: เพิ่มความยาก

เปิด [spawn_obstacle_เพิ่มความยาก.gd](02_ต่อยอดเพิ่มความยาก/spawn_obstacle_เพิ่มความยาก.gd) แล้วนำฟังก์ชันไปแทน `_spawn_obstacle()` ใน `main.gd` ของเกมสมบูรณ์ ไม่ต้องสร้าง script แยก ฟังก์ชันนี้ใช้ตัวแปรและ Node จาก `main.gd` เดิม

ทุก 15 วินาทีที่รอด วัตถุใหม่จะเกิดถี่ขึ้นและตกเร็วขึ้น โดยช่วงเกิดไม่ต่ำกว่า 0.25 วินาที และความเร็วไม่เกิน 600 พิกเซลต่อวินาที ทดลอง Game Over และเริ่มเกมใหม่หลังแก้ไขด้วย

## วิธีดาวน์โหลด

กด **Code → Download ZIP** แล้วแตกไฟล์ หรือเปิดแต่ละไฟล์บน GitHub เพื่อคัดลอกโค้ดได้โดยตรง Repository นี้มีเฉพาะโค้ดและคำแนะนำ ไม่มี Scene หรือ assets จึงต้องสร้างโปรเจกต์ตามสไลด์ก่อนนำโค้ดไปใช้
