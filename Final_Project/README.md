# Dodge Rain

เปิด project.godot ด้วย Godot 4.7.2 Standard แล้วกด F5

A/D หรือ Left/Right: ขยับเพื่อหลบสิ่งกีดขวาง คะแนนคือเวลาที่รอด ชนแล้ว Game Over กด R หรือ Enter เพื่อเริ่มใหม่

960×540, Compatibility, GDScript. มี background และเสียงชน ไม่มี dependency ภายนอก ไม่ต้องใช้ไดรฟ์ U: สามารถแตกไว้ในโฟลเดอร์ของคุณเองได้

สำหรับวิทยากร: นี่คือโค้ดอ้างอิงฉบับสมบูรณ์ แจกเมื่อจบ workshop คู่มือผู้เรียนและ checkpoints อยู่ในชุด Workshop Pack แยกต่างหาก
