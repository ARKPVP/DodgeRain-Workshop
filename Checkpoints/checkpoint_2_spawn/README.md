# checkpoint_2_spawn

จุดที่อยู่: นาที 115: Random spawn

เสร็จแล้ว: Player, Obstacle, Timer, PackedScene, สุ่ม X, ตกและลบเมื่อหลุดจอแล้ว

ทำต่อ: เพิ่ม UI, signals, collision handler, score, game over และ restart

## วิธีใช้

1. เก็บโปรเจกต์เดิมไว้ก่อน แตก ZIP เป็นโฟลเดอร์ใหม่ในเครื่องของคุณเอง
2. เปิด Godot 4.7.2 Standard แล้ว Import ไฟล์ project.godot ในโฟลเดอร์นี้
3. รอ import assets แล้วกด F5 ใช้ A/D หรือ Left/Right
4. Checkpoint 3 กด R หรือ Enter หลัง Game Over เพื่อเริ่มใหม่

Checkpoint เป็นไฟล์ช่วยตามช่วงเรียน วิทยากรแจกเฉพาะเมื่อผู้เรียนติดตาม gate ไม่ทัน ไม่แจกเฉลยทั้งหมดตั้งแต่ต้น
